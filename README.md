# Git & GitHub Practical Project

## 📌 Project Overview

This project was created as part of a practical exercise to learn and demonstrate the fundamentals of **Git and GitHub**.

The project covers Git installation, configuration, repository creation, cloning, file tracking, commits, remote repositories, branching, merging, `.gitignore`, and pushing changes to GitHub.

## 🎯 Objectives

The main objectives of this project were to:

- Install and configure Git
- Configure Git username and email
- Create and manage a GitHub repository
- Clone a remote repository to a local machine
- Create and manage project files
- Track and commit changes using Git
- Push changes to GitHub
- Create and work with Git branches
- Merge a feature branch into the `main` branch
- Create and configure a `.gitignore` file
- Understand the basic Git workflow

## 🛠️ Technologies Used

- Git
- GitHub
- Linux / WSL
- Terminal
- Markdown
